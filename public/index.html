What the hell is this?

DollaDesk is a dead-simple invoice tracker for freelancers and side-hustlers. You do work → you add an invoice → you mark it paid when money lands. Top bar always tells you billed / paid / pending / overdue. That's it.

📦 Like a package manager, but for money
Each invoice is a package: client = name, amount = version, status = paid/pending, just like installed vs. available.
⚡ 30 seconds to use
No login. Add client + amount + due date. Search, sort, filter, export CSV for taxes.
🔌 Real API inside
Every button calls /api/.... Bots and automations can use the same endpoints. See API docs.
Open the tracker ↓ How the API works

How it works (3 steps)

  1. Add — client, amount in USD, due date, optional note like "Logo design".
  2. Track — overdue rows turn red, search filters as you type, chips show All / Pending / Paid.
  3. Get paid — hit Mark paid, watch Pending drop to $0, hit Export CSV at tax time.
